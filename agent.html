01 — Architecture

Harness 层行为约束

不是写更好的 prompt，而是构建约束 AI 行为的 harness。灵感来自 Andrej Karpathy 的 Skills 项目——用 Markdown 文件约束 LLM 行为。Anthropic 和 OpenAI 的 Harness Engineering 博客是理论基础。整套系统模型无关，换模型只需改路由配置。

📐

分层指令架构

71 行常驻指令 + 领域模块按需加载。旧版 234 行全量注入，优化后每轮上下文消耗大幅减少。薄路由入口识别任务关键词，自动加载对应领域文件。

🧠

Memory 语义路由

43 个结构化记忆文件，按关键词触发按需加载。新项目、工具跑通、品牌决策、用户反馈自动归档。跨 session 知识不丢失，每个新 session 自动继承上下文。

🛡️

Skills 标准化

9 个可复用 Skill 模板，统一 frontmatter 字段（agent、allowed-tools、max_turns、铁律）。内置失败护栏：连续失败 2 次停止，30 步无输出自动中断。

02 — Three-Layer Routing

Plan → Exec → Escalate

三层路由是整个系统的调度骨架。前期在 Notion 用强推理模型出完整方案，锁定后执行。执行阶段自动拆分并行 Agent，失败自动升档重试。后期标准归档，决策写入 Memory 供后续复用。

安全网。不死磕轻量模型，自动切回强推理模型重试。结果统一审查合并。

交叉审计循环

视觉产出不信任单一模型。图像生成模型出图 → 视觉理解模型审计 → 生成模型迭代 → 第三模型终审。谁产出谁不审自己，消除同源偏差。引入 GLM-5V 做设计辅助、numpy 像素级审计、语义审计三层门禁。

03 — Local Multimodal

视觉能力前置

主模型缺多模态能力时自动激活本地辅助链。不是所有任务都需要调云端 API，本地能做的就本地做。零 API 成本，Apple Silicon 原生加速。

🎙️

mlx-whisper 音频转写

Apple Silicon 本地运行，whisper-small-mlx 模型。10MB MP3 约 40 秒转写完成。零 API 成本，中文效果好。

📷

Pillow + NumPy 照片挑片

时间聚类 → 清晰度评分（Laplacian 方差）→ 曝光质量 → 对比度加权选最佳帧。纯本地算法，零成本。

🎨

GLM-5V 视觉审计

审美判断、品牌色审计、设计迭代辅助。GLM-5V-Turbo 首选，GLM-4.6V 回退。单张约 2500 tokens。

👁️

Qwen3-VL 空间分析

OCR 文字提取、色值识别、空间布局分析。Ollama 本地部署，4B 参数量，离线可用。

🔐

Logo 双重验证

感知哈希（pHash）加 sips 像素取证。AI 生成的 Logo 可能看着像但细节不对，双重验证确保品牌一致性。

📄

Chrome Headless PDF

HTML → PDF 渲染，处理 #→%23 编码问题和 flex 分页兼容性。用于品牌报告和文档交付。

Prefix Cache 优化

轻量模型缓存命中率一度 58%，实际成本是强推理模型五倍。标准化 prompt 前缀 + 批量合并后，DeepSeek Pro 稳定 97.9%，MiMo 超 90%。

05 — Evolution

版本迭代

从双模型路由到多 Agent 编排平台，每个版本都是从实际项目踩坑中长出来的。理论来自 Karpathy Skills、Harness Engineering、Reasonix 三层路由，实战来自医疗器械视频、教育品牌营销、展会视频等多领域交付。

v3.0

双模型路由 + 并行优先

Opus Plan / Flash Exec 分工，引入并行调度策略。奠定 Plan → Exec 二层骨架。

v3.1 – v3.2

MCP 接入 + 成本工程

小红书 MCP 服务接入，隐身浏览器反检测。发现 Flash 缓存失效导致 5 倍成本差，启动 Prefix Cache 优化。

v3.6

Reasonix 三层路由

引入 Escalate 层：执行模型连续失败 2 次自动切更大参数推理模型。Plan → Exec → Escalate 三层定型。

v3.7 – v3.8

视觉路由 + Memory 语义路由

视觉任务强制路由给 Codex 执行，主模型只做推理和审查。Memory 系统从 39 个文件发展到 43 个，关键词触发按需加载。

v4.0

全仓标准化 + Handoff 协议

项目目录标准模板、Skills 标准化、Session Handoff 机制。跨 session 知识不丢失。

v4.1

MiMo 原生接入 + 模型无关

小米 MiMo 三层变体全面接入。MCP 服务器实现跨模型调用。整套 harness 脱离 DeepSeek 硬编码，实现模型无关。
